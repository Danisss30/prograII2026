# Semana 2 - Calculadora de Edad

## Nombre de la actividad

Calculadora de Edad con Variables y Operadores.

## Descripción breve del programa

Este programa fue realizado en Java y permite calcular la edad aproximada de una persona utilizando su año de nacimiento y el año actual. También calcula la edad aproximada en meses y determina si la persona es mayor de edad.

## Datos solicitados

El programa solicita los siguientes datos:

* Nombre completo.
* Carné.
* Año de nacimiento.
* Año actual.

## Cálculos realizados

El programa realiza los siguientes cálculos:

* **Edad aproximada:** se resta el año de nacimiento al año actual.
* **Edad aproximada en meses:** se multiplica la edad aproximada por 12.
* **Mayoría de edad:** se utiliza una comparación para determinar si la edad es mayor o igual a 18 años y el resultado se guarda en una variable `boolean`.

La edad se muestra como aproximada porque solamente se utilizan los años y no se toma en cuenta el mes ni el día de nacimiento.

## Instrucciones para ejecutar el proyecto

1. Abrir el proyecto en IntelliJ IDEA.
2. Abrir la carpeta `src`.
3. Abrir el archivo `CalculadoraEdad.java`.
4. Ejecutar el método `main`.
5. Ingresar los datos solicitados en la consola.
6. Revisar los resultados mostrados.
